# 전기화학 데이터 예시 폴더

이 폴더에 Rate Capability(율특성) 등의 전기화학 데이터 예시 파일을 넣어주세요.
넣어주신 데이터를 기반으로 웹 애플리케이션에서 분석 및 시각화 기능 등을 구현하도록 하겠습니다.

## 파일 업로드 안내
* 지원 예정 형식: `.csv`, `.xlsx`, `.txt` 등
* 데이터 분석 시 필요한 주요 열(Column):
  * 전류 밀도 (Current density) 또는 C-rate
  * 비용량 (Specific capacity) 또는 방전 용량 (Discharge capacity)
  * 사이클 번호 (Cycle number)
  * 전압 (Voltage), 전류 (Current) 등
